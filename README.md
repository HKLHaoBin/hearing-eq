# 听感测听 → 参数 EQ

在浏览器里对纯音选「听得到」或「听不到」，按相对听阈给出四段参数 EQ（频点、Q、增益）。单页、无后端、数据不离开你的设备。

**不是医学测听，不能代替听力诊断。**

在线使用：<https://hklhaobin.github.io/hearing-eq/>

## 如何测听

1. 戴耳机，找安静环境。建议有线耳机（部分蓝牙会把左右混成单声道）。
2. 打开页面，播放 1 kHz 参考音，把系统音量调到清楚但不刺耳，之后不要再动音量。
3. 选快速（4 个频点）或完整（8 个频点）；可选双耳一起，或先左后右。
4. 每个音播放完后选 **听得到** 或 **听不到**。偶发静音是测谎，请照实选。
5. 结束后查看建议 EQ。补偿强度可在温和 / 均衡 / 完整之间切换。
6. 需要发给别人或自己留档时，点「复制结果」。

本地打开：用浏览器打开 `index.html`，或在本目录执行 `python3 -m http.server 8765` 后访问 <http://127.0.0.1:8765/>。

## 目标 EQ 的四段范围

建议频点会落在这些硬限制内（常见四段耳机 EQ）：

| 段 | 频点范围 | 默认类型 |
|----|----------|----------|
| 1 | 20–200 Hz | lowshelf |
| 2 | 210–3000 Hz | peaking |
| 3 | 3100–5000 Hz | peaking |
| 4 | 5100–10000 Hz | highshelf |

12 kHz 等超出第 4 段上限的弱点，用 10000 Hz 高架近似补偿。

## 结果怎么算

- 每个频点用简化的 Hughson–Westlake 阶梯（听得到降 10 dB，听不到升 5 dB）估相对阈值。
- 播放时按 ISO 226 等响曲线做相对加权，避免低音/高音单纯因为等响差异看起来「更差」。
- 增益按「相对参考频点的损失 × 补偿强度」计算，默认半增益（0.5），单段上限 +12 dB，并给出前置衰减以防削波。
- 若某频点打到测听下限，不会把它当作 0 dB 参考，以免低频被抬得过猛。

测听结果同时包含耳机频响和耳朵本身，换耳机需要重测。
